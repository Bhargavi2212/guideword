| 2026-10-11 | LOPA values (initiating events, protection layers, modifiers, tolerable frequencies) come from EGPC-PSM-GL-015 (2022), which tabulates CCPS typical values. | Free, public and citable; the CCPS books themselves are paid. | 2026-10-11 | Severity class definitions are a Guideword default (people safety), labelled as such and editable. | No free public source defines the classes; EGPC defers to a corporate matrix. |
