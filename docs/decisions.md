| 2026-10-11 | LOPA values (initiating events, protection layers, modifiers, tolerable frequencies) come from EGPC-PSM-GL-015 (2022), which tabulates CCPS typical values. | Free, public and citable; the CCPS books themselves are paid. Values cross-checked against Crowl & Louvar via the University of Michigan tutorial. |
| 2026-10-11 | Default tolerable frequencies use the EGPC typical TMEL levels (1e-2 to 1e-6 per year for S1–S5), not UK HSE R2P2. | R2P2 gives individual-risk boundaries for people, not per-scenario LOPA targets; the TMEL table maps directly to severity classes. Companies load their own. |
| 2026-10-11 | Severity class definitions are a Guideword default (people safety), labelled as such and editable. | No free public source defines the classes; EGPC defers to a corporate matrix. |
| 2026-10-11 | Tennessee Eastman simulator: use the open-licence Python package `tennessee-eastman-profbraatz` (University of Illinois licence, permissive; pure-Python backend; 20 disturbances; open and closed loop). | Licence permits use, modification and redistribution with attribution; no MATLAB needed.
